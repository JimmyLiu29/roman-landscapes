# Local build and verification

From the repository root, create a Python environment and install the pinned dependencies as shown in the README. Run `bin/acquire` to restore the four Natural Earth inputs and ten foundation files into `data/raw/`. The acquisition checks each input against the source manifest. Once these files and the vendored browser libraries are available the build runs offline.

Run `bin/build` and `bin/verify`. The build creates the shaded-relief PMTiles archive, five physical vector collections, four foundation geometry collections, catalog, relations, detail shards and source credits. It embeds the application shell inventory in the service worker. Verification checks release bounds, checksums, feature IDs, file inventories and relief tiles. Run `bin/serve` and open http://127.0.0.1:4173.

For browser regression, install Playwright with Chromium and run `node tests/browser.mjs`. The harness serves the local build on a loopback port, exercises map interaction and both reading panels, saves the complete package, stops the server and restarts Chromium offline. Set `PLAYWRIGHT_MODULE` or `CHROMIUM_PATH` when using an existing installation. Supplying the deployed origin as an argument runs anonymous online checks against that origin.

The application stores verified package files in origin-private file storage. To use the atlas offline, select **Enable offline use** and wait for verification. **Verify saved maps** rechecks each saved file. **Remove saved maps** clears the package. When a compatible data release is available online, select **Update saved maps**. The atlas downloads to a separate directory, checks each checksum, decompresses the package and checks the catalog’s detail references before switching versions. A cancelled or failed transfer leaves your current release available. Use **Reload updated atlas** to accept a new application shell. After browser storage loss or damage, select **Remove saved maps**, reconnect and download again. Browsers that decline persistent storage may evict the package under storage pressure.

Run the parser regressions with `.venv/bin/python -B -m unittest discover -s tests`. Use `bin/serve 4174 --host 127.0.0.1` to change the local port or address.
