# Local build and verification

From the repository root, create a Python environment and install the pinned dependencies as shown in the README. Use `bin/acquire` (default `--scope all`) to verify the full inventory. Direct sources can be restored from their pinned URLs. Supply locked snapshots at the paths and SHA-256 digests in the source manifest. Two companion assets are tracked in the repository. Use `bin/acquire --scope foundation` for the direct foundation subset.

The v0.2 catalog contains 75,223 records from 16 active sources, including 23,385 economic evidence records and 324 historical events. Of 1,208 people, 414 have activity or event locations and 944 have biographical locations. The groups overlap by 150 people, leaving 794 with biographical locations only. The historical links reach 383 town nodes. The complete offline package occupies 57,448,450 bytes (54.8 MiB / 57.45 MB).

Run `bin/build` and `bin/verify`, then `bin/serve` to open the atlas on loopback. Edit guide text in `docs/about-methods.md` or `docs/datasets.md` and run `scripts/render_docs.py` with Python before building. Use `--check` to compare the HTML, release counts and package size. Browser tests use Chromium 151 and Playwright. Set `PLAYWRIGHT_MODULE` and `CHROMIUM_PATH` for a local installation. Run `node tests/browser.mjs` against dist or add `--fixture` for the synthetic atlas. Set `ATLAS_EVIDENCE` to store the report and screenshots. For the full two-version migration, set `ATLAS_LEGACY` to a retained v0.1 site. The macOS full run reuses two verified build inventories or invokes `python3 tests/rebuild.py EVIDENCE` to create them under a network-denying policy. Supply `--reference DIRECTORY` to the rebuild command to compare the package with a retained release.

The application stores verified package files in origin-private file storage. To use the atlas offline, select **Enable offline use** and wait for verification. **Verify saved maps** rechecks each saved file. **Remove saved maps** clears the package. When a compatible data release is available online, select **Update saved maps**. The atlas downloads to a separate directory, checks each checksum, decompresses the package and checks the catalog’s detail references before switching versions. A cancelled or failed transfer leaves your current release available. Use **Reload updated atlas** to accept a new application shell. After browser storage loss or damage, reconnect and select **Repair offline maps**. Browsers that decline persistent storage may evict the package under storage pressure.

When you open the new atlas online with a saved v0.1 package, the browser installs the new service worker. You can activate it immediately with **Reload updated atlas**. If you close all tabs and installed windows for the atlas, the waiting worker activates automatically after the last controlled page closes. On the next visit, connect to the network and select **Enable offline use** to download the complete v0.2 package. The old package remains in storage until replacement succeeds or you remove it.

Run the parser regressions with `.venv/bin/python -B -m unittest discover -s tests`. Use `bin/serve 4174 --host 127.0.0.1` to change the local port or address.
